# Adding Hyderabad Areas

1. Open `src/data/initial-areas.ts`
2. Add an area with `parentId: "loc-hyderabad"`
3. Provide verified local characteristics and property types
4. Set `localDataVerified: true` and `contentReviewed: true` before publishing
5. Run page creation + audits

Example URL:

`/locations/hyderabad/your-area-slug/`
